# Related repositories

This repository, `pmusaraj/forum-index-app`, contains the native iOS and macOS app.
Prompts will often refer to these companion repositories:

- `pmusaraj/forum-index`: the backend.
- `pmusaraj/forum-index-android`: the Android app.

Local checkouts are often sibling folders named `forum-index`,
`forum-index-android`, and `forum-index-app`. Look for those siblings when a task
refers to the backend or Android app. When working in a Git worktree, also check
beside the main checkout (located with `git worktree list`); the companion repos
may not be adjacent to the worktree. Verify the checkout's remote before using it.
